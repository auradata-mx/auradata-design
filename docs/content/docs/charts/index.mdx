---
title: Gráficas
description: "Elige una gráfica según lo que necesites mostrar en tus datos."
---

- **Compara series o muestra tendencias** con [Cartesian Chart](/docs/components/cartesian-chart/) o usa [Sparkline](/docs/components/sparkline/) cuando tengas poco espacio.
- **Muestra partes de un total** con [Donut Chart](/docs/components/donut-chart/) o **conversiones entre etapas** con [Funnel Chart](/docs/components/funnel-chart/).
- **Muestra patrones en una cuadrícula** con [Heatmap](/docs/components/heatmap/) o **un valor frente a una meta** con [Gauge](/docs/components/gauge/).

Para construir otra gráfica, usa [Chart](/docs/components/chart/) para compartir colores, leyenda y detalles emergentes. Usa [Chart Card](/docs/components/chart-card/) para añadir un título, estados de carga y acciones.
