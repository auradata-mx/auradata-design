---
title: Introducción
description: El sistema de diseño de AuraData, la marca y los componentes con los que se construyen sus productos.
---

AuraData Design reúne en un mismo lugar lo que necesita un producto de AuraData para verse y comportarse como tal:

- **Los tokens**: la marca como datos (colores en claro y oscuro, tipografía, radios, sombras, movimiento y paletas de gráficas), en CSS, Tailwind 4, shadcn, Docusaurus, antd y ECharts.
- **El registro**: componentes de React sobre Base UI y Tailwind 4, con la marca aplicada, que se instalan con el CLI de shadcn y quedan en tu código.
- **Storybook**: el taller donde se prueba cada estado de cada componente, con pruebas visuales y de accesibilidad.
