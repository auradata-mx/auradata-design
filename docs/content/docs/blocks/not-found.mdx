## Componentes del registro

`Logo` mantiene la identidad de la app. `Button` se renderiza como enlace porque la acción cambia de página.

## Cómo adaptarlo

Registra `NotFound` como la pantalla 404 de tu enrutador. El enlace usa `/` por defecto; pasa `homeHref` si la ruta de inicio es otra. En la vista previa, el enlace lleva a un inicio simulado.
