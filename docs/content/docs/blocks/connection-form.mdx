## Componentes del registro

`Field` agrupa etiquetas, ayudas y errores. `Input`, `Select`, `NumberInput`, `PasswordInput` y `Switch` capturan los valores; `Alert` muestra errores generales. La validación usa React Hook Form y Zod.

## Cómo adaptarlo

Conecta `onSubmit` al guardado en tu servidor. Devuelve errores con el nombre del campo correspondiente o con `form` para mostrarlos arriba. Usa `defaultValues` para precargar datos y `onCancel` para volver al lugar desde donde se abrió el formulario.
