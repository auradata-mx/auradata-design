---
title: Button group
description: "Agrupa acciones o controles que pertenecen a una misma tarea."
---

El grupo de AuraData une los bordes de sus partes. Entre dos botones sólidos, el separador ocupa toda la altura; junto a un campo, las partes comparten su borde de contraste 3:1.

## Instalación

<ComponentInstall item="button-group" />

## Uso

```tsx
import { Button } from '@/components/ui/button';
import { ButtonGroup } from '@/components/ui/button-group';

<ButtonGroup aria-label="Acciones del informe">
  <Button variant="outline">Publicar</Button>
  <Button variant="outline">Compartir</Button>
</ButtonGroup>;
```

## Cuándo usarlo

- Agrupa acciones estrechamente relacionadas, o un campo y su acción. Etiqueta el grupo según lo que se hace con él.

## Cuándo no

- Para elegir una sola vista o un valor persistente, usa `Tabs` o `ToggleGroup`; agrupar botones no los vuelve opciones.
