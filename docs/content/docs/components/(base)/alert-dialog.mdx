El diálogo de alerta de shadcn con un velo que se lee en oscuro, la elevación modal, un ícono (`AlertDialogMedia`) cuyo fondo también se lee en oscuro y, en el teléfono, botones del pie apilados a 40 px. A diferencia de `Dialog`, no se cierra al hacer clic fuera: hay que elegir.

## Uso

```tsx
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
} from '@/components/ui/alert-dialog';
import { Button } from '@/components/ui/button';

<AlertDialog>
  <AlertDialogTrigger render={<Button variant="destructive" />}>Eliminar informe</AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>¿Eliminar informe?</AlertDialogTitle>
      <AlertDialogDescription>Se borran «Ventas 2026», sus 12 gráficas y sus filtros. No se puede deshacer.</AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Cancelar</AlertDialogCancel>
      <AlertDialogAction variant="destructive">Eliminar</AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>;
```

`AlertDialogCancel` cierra el diálogo; `AlertDialogAction` es un `Button` que no lo cierra solo: corre tu acción y ciérralo tú (ver «Con la acción conectada»).

Con `size="sm"`, para una pregunta corta: el texto centrado y los dos botones lado a lado.

## Cuándo usarlo

- **Antes de borrar o de algo que no se puede deshacer**: el título pregunta («¿Eliminar informe?») y la descripción nombra el objeto y la consecuencia («Se borran sus gráficas y filtros. No se puede deshacer.»).
- **Verbos en los botones**: «Eliminar», «Cancelar», «Seguir editando»; nunca «Aceptar» ni «OK».
- **La acción destructiva** con `variant="destructive"`, en el trigger y en el botón que confirma.

## Cuándo no

- **Una tarea corta** (renombrar, compartir): `Dialog`.
- **Avisar que algo salió bien**: un toast de `Sonner`, no un diálogo.
