El tooltip de shadcn con una flecha que no toca el trigger, 8 px de margen con el borde de la pantalla y espacio para un `Kbd` con el atajo. `TooltipProvider` lo abre sin espera (`delay={0}`) y, entre tooltips vecinos, salta de uno a otro sin volver a esperar.

## Uso

```tsx
import { Button } from '@/components/ui/button';
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from '@/components/ui/tooltip';

<TooltipProvider>
  <Tooltip>
    <TooltipTrigger render={<Button variant="outline" size="icon" aria-label="Actualizar datos" />}>
      <RefreshCwIcon aria-hidden />
    </TooltipTrigger>
    <TooltipContent>Actualizar datos</TooltipContent>
  </Tooltip>
</TooltipProvider>;
```

Pon un `TooltipProvider` cerca de la raíz de la app; cada tooltip lo comparte. El tooltip se abre al pasar el mouse o al enfocar el trigger con Tab, y Escape lo cierra.

## Cuándo usarlo

- **Un botón de solo ícono** siempre lleva un tooltip con el mismo texto que su `aria-label`, para quien usa el mouse.
- **El atajo de una acción**, con `Kbd`.
- **Una pista corta**, de una línea; un texto largo salta de línea al ancho máximo (`max-w-xs`), pero mejor acórtalo.

## Cuándo no

- **Lo único que explica algo**: en el teléfono no hay mouse. Si hay que leerlo, déjalo a la vista o en la descripción de un `Field`.
- **Contenido con enlaces o controles**: `Popover`; para el resumen de un enlace, `HoverCard`.
- **El valor de una gráfica**: el tooltip del `Chart`, que pone el valor primero.
