La versión de AuraData del scroller de shadcn etiqueta en español los botones para ir al inicio y al final. El proveedor comparte el estado de desplazamiento entre la lista y sus controles.

<ComponentPreview name="message-scroller/demo" align="start" />

## Instalación

<ComponentInstall item="message-scroller" />

## Uso

```tsx
import {
  MessageScroller,
  MessageScrollerButton,
  MessageScrollerContent,
  MessageScrollerItem,
  MessageScrollerProvider,
  MessageScrollerViewport,
} from '@/components/ui/message-scroller';

<MessageScrollerProvider>
  <MessageScroller className="h-64">
    <MessageScrollerViewport aria-label="Mensajes">
      <MessageScrollerContent aria-live="polite">
        <MessageScrollerItem messageId="1">El informe está listo.</MessageScrollerItem>
      </MessageScrollerContent>
    </MessageScrollerViewport>
    <MessageScrollerButton behavior="instant" />
  </MessageScroller>
</MessageScrollerProvider>;
```

## Ejemplos

### Mensajes nuevos

Con identificadores estables, puedes agregar mensajes sin recrear los anteriores. La región viva anuncia nuevas respuestas.

## Cuándo usarlo

- En chats o históricos de conversación, da altura al contenedor y una identidad estable a cada mensaje.

## Cuándo no

- Para una región desplazable sin comportamiento de chat, usa `ScrollArea`. Usa `Bubble` para el contenido de un turno, no para el historial.
