El toggle group de shadcn sobre Base UI; sus elementos solo con ícono son cuadrados, como el `Toggle`. Con `spacing={0}` se unen en una sola barra.

<ComponentPreview name="toggle-group/demo" />

## Instalación

<ComponentInstall item="toggle-group" />

## Uso

```tsx
import { ChartColumnIcon, ChartLineIcon } from 'lucide-react';
import { ToggleGroup, ToggleGroupItem } from '@/components/ui/toggle-group';

<ToggleGroup defaultValue={['barras']} aria-label="Tipo de gráfica">
  <ToggleGroupItem value="barras" aria-label="Barras">
    <ChartColumnIcon aria-hidden />
  </ToggleGroupItem>
  <ToggleGroupItem value="lineas" aria-label="Líneas">
    <ChartLineIcon aria-hidden />
  </ToggleGroupItem>
</ToggleGroup>;
```

El valor es siempre un arreglo (`['barras']`), aun con una sola opción.

## Ejemplos

### Outline unido

`variant="outline"` y `spacing={0}`: una sola barra con texto.

## Cuándo usarlo

- **Opciones de una barra de herramientas**: el tipo de gráfica, la alineación, las series visibles.
- **El grupo lleva `aria-label`** («Tipo de gráfica») y cada elemento solo con ícono, el suyo.

## Cuándo no

- **Cambiar entre secciones con su propio panel de contenido**: `Tabs`.
- **Secciones con contenido distinto**: `Tabs`.
- **Una opción en un formulario**: `RadioGroup` o `Select`.
