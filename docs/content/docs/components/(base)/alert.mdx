Las variantes de AuraData tiñen el fondo y el ícono, no el texto. Si agregas una acción, ocupa su propia columna o baja debajo del texto cuando el espacio es estrecho.

## Instalación

<ComponentInstall item="alert" />

## Uso

```tsx
import { Alert, AlertTitle } from '@/components/ui/alert';

<Alert variant="info">
  <AlertTitle>El informe se actualiza cada hora</AlertTitle>
</Alert>;
```

## Ejemplos

### Con una acción

## Cuándo usarlo

- Mantén visible algo que afecta a la página hasta que cambie la causa. Nombra qué pasó y, si hay un paso útil, ponle un verbo.

## Cuándo no

- Para un aviso de toda la app, usa `AnnouncementBanner`; para confirmar una acción, un toast de `Sonner`.
