`Trace` agrupa los pasos de una operación, como una consulta del chat. El disparador de un paso desplegable tiene al menos 24 px de alto. Los estados `running`, `error` y `pending` cambian el aspecto de la línea.

## Instalación

<ComponentInstall item="trace" />

## Uso

```tsx
import { Trace, TraceLine, TraceTitle } from '@/components/ui/trace';

<Trace>
  <TraceLine status="running"><TraceTitle>Consultando ventas…</TraceTitle></TraceLine>
</Trace>;
```

## Ejemplos

### Un paso que falló

Nombra la falla con palabras, no solo con el color. Al abrir el paso, explica qué pasó y qué puede hacer la persona.

## Cuándo usarlo

- Para mostrar cómo avanzó una operación y dejar sus detalles técnicos bajo demanda. Usa `TraceIcon` solo como apoyo del texto.

## Cuándo no

- Para mostrar código sin un paso asociado, usa `CodeBlock`. Si falla toda la vista, usa `EmptyError` con un siguiente paso claro.
