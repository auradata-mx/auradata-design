---
title: Carousel
description: "Recorre una serie de tarjetas relacionadas con flechas o teclado."
---

El carrusel conserva el gesto de desplazamiento de Embla, actualiza el estado de sus flechas al siguiente cuadro y les da etiquetas en español.

<ComponentPreview name="carousel/demo" />

## Instalación

<ComponentInstall item="carousel" />

## Uso

```tsx
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselNext,
  CarouselPrevious,
} from '@/components/ui/carousel';

<Carousel aria-label="Vistas del producto">
  <CarouselContent>
    <CarouselItem>Tablero de ventas</CarouselItem>
    <CarouselItem>SQL Lab</CarouselItem>
  </CarouselContent>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>;
```

## Ejemplos

### Dos tarjetas en vistas anchas

Cambia el ancho de las tarjetas con un breakpoint. Mantén las flechas debajo para que no se salgan de una vista estrecha.

## Cuándo usarlo

- Para recorrer capturas o testimonios relacionados. Dale un nombre a la región, etiqueta las diapositivas y conserva los controles visibles.

## Cuándo no

- Para comparar filas de datos sin ocultarlas fuera de la vista, usa `DataTable`.
