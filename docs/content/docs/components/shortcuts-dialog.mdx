Un componente de AuraData sobre `Dialog` y `Kbd`: los atajos agrupados («Navegación», «Informes», «General»), cada tecla en un `Kbd`, `mod` escrito como la búsqueda (⌘ en Apple, Ctrl en lo demás) y las secuencias como «G luego I». Se abre con «?» desde cualquier parte menos un campo de texto, donde «?» es solo un carácter.

En este ejemplo también puedes pulsar «?» fuera de un campo de texto.

## Uso

```tsx
import { ShortcutsDialog, type ShortcutGroup } from '@/components/ui/shortcuts-dialog';

const groups: ShortcutGroup[] = [
  {
    heading: 'Navegación',
    shortcuts: [
      { label: 'Buscar', keys: 'mod+k' },
      { label: 'Ir a informes', keys: 'g i' },
    ],
  },
  {
    heading: 'General',
    shortcuts: [{ label: 'Ver los atajos', keys: '?' }],
  },
];

<ShortcutsDialog groups={groups} />;
```

Ponlo una vez, en el layout de la app. Cómo se escriben las teclas: `mod+k` (⌘K o Ctrl K), `shift+d`, `esc`, `?`, y un espacio entre los pasos de una secuencia (`g i` se lee «G luego I»). Para abrirlo desde un botón o un menú, contrólalo con `open` y `onOpenChange`, como en el ejemplo.

## Cuándo usarlo

- **Los atajos de la app**, todos en un lugar. Se abre con «?» fuera de los campos de texto; las teclas van en `Kbd`.
- **Agrupados por dónde se usan**, con verbos: «Buscar», «Ir a informes», «Guardar cambios».
- **Una entrada para encontrarlo**: «Ver los atajos» en la lista misma, y en la ayuda del `UserMenu`.

## Cuándo no

- **Enseñar un solo atajo**: un `Kbd` en el `Tooltip` del botón.
- **Buscar y correr acciones**: `SearchCommand`.
