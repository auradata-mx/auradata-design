---
title: Data table selection bar
description: "Da acceso a acciones en bloque mientras hay filas seleccionadas."
---

`DataTableSelectionBar` flota abajo cuando hay una selección. Anuncia el conteo con una región viva; «Quitar selección» y Escape dentro de la barra llaman a `onClear`. `DataTable` ya la incluye cuando le pasas `bulkActions`.

<ComponentInstall item="data-table-selection-bar" />

## Uso

```tsx
import { DataTableSelectionBar } from '@/components/ui/data-table-selection-bar';

<DataTableSelectionBar count={seleccion.length} onClear={quitarSeleccion}>
  {acciones}
</DataTableSelectionBar>;
```

## Cuándo usarlo

- Para acciones que aplican a varios elementos, en tablas o listas. Deja que el componente que tiene la selección calcule el conteo.

## Cuándo no

- Si la acción afecta solo una fila, va en esa fila. Con `DataTable` y `bulkActions`, no agregues una segunda barra.
