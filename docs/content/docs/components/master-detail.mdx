---
title: Master detail
description: "Abre el detalle de un elemento sin perder de vista su lista."
---

`MasterDetail` muestra una lista y el elemento abierto en dos paneles. Por debajo de `md`, el detalle reemplaza a la lista. Al abrirlo recibe el foco y, al volver, el foco regresa a la fila que lo abrió.

<ComponentPreview name="master-detail/demo" align="start" />

## Instalación

<ComponentInstall item="master-detail" />

## Uso

```tsx
import { MasterDetail, MasterDetailList, MasterDetailPane } from '@/components/ui/master-detail';

<MasterDetail showDetail={informe !== null}>
  <MasterDetailList aria-label="Informes">{filas}</MasterDetailList>
  <MasterDetailPane aria-label="Detalle del informe">{detalle}</MasterDetailPane>
</MasterDetail>;
```

## Ejemplos

### Un informe abierto

La vista controla la selección. Marca la fila con `active` y nombra el botón de regreso por la lista que recupera: «Informes».

## Cuándo usarlo

- Para navegar entre informes, conexiones u otros elementos cuando la lista da contexto al detalle. Nombra ambos paneles.

## Cuándo no

- Para comparar filas por columnas, usa `DataTable`. Para una acción breve que debe completarse antes de seguir, usa `Dialog`.
