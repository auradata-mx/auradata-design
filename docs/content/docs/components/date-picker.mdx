Un selector de fecha de AuraData sobre nuestro `Calendar` en español, que se ve como un campo de formulario. Elegir un día cierra el calendario y devuelve el foco al campo; el día se lee «21 nov 2026». `DateTimePicker` pone una lista de horas de 24 horas junto al calendario, en un solo valor.

## Instalación

<ComponentInstall item="date-picker" />

## Uso

```tsx
import { DatePicker } from '@/components/ui/date-picker';

<DatePicker id="due" value={date} onValueChange={setDate} />;
```

El valor es un `Date`, o `undefined` sin día. Con el teclado: Enter abre en hoy, las flechas se mueven por día y semana, Enter elige y Escape cierra.

## Cuándo usarlo

- **Un día en un formulario**: una fecha de entrega, de envío, de corte.
- **En formularios**, con `react-hook-form`: no es un input nativo, así que va con `Controller` (`value` y `onValueChange`).
- **Fija `today` en pruebas e historias**, para que el calendario no cambie con el reloj.

## Cuándo no

- **Solo una hora**: `TimePicker`.
- **El periodo de un informe**: `DateRangeFilter`.
- **Un calendario siempre visible**: `Calendar`.
