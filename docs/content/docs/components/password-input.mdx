Un campo de contraseña de AuraData con el botón «Mostrar contraseña» (dice si se ve con `aria-pressed`) y `PasswordStrength`, un medidor sobre `Meter` de Base UI: cuatro segmentos, el nivel en palabras («Seguridad: Buena») y las reglas que faltan. Los lectores de pantalla oyen el nivel como el valor del medidor.

## Uso

```tsx
import { PasswordInput } from '@/components/ui/password-input';

<PasswordInput id="password" />;
```

Por omisión es `autoComplete="current-password"`: el navegador llena la guardada. Al elegir una nueva, pasa `autoComplete="new-password"` para que ofrezca generarla.

## Ejemplos

### Contraseña nueva

El medidor y las reglas siguen lo que se escribe. Una contraseña común es débil aunque mezcle de todo, y el medidor dice por qué.

La confirmación no coincide: borde rojo nítido, el texto conserva su color.

## Cuándo usarlo

- **Iniciar sesión**: solo `PasswordInput`, con la contraseña guardada.
- **Elegir una contraseña**: `PasswordInput` con `new-password` y `PasswordStrength` debajo, unido con `aria-describedby`.

## Cuándo no

- **Un código de verificación**: `InputOTP`.
- **Un token o una llave de API que se copia**: `InputGroup` con un botón de copiar.
