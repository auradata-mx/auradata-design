Un componente de AuraData armado con `Command`: el botón «Buscar…» con su atajo en `Kbd`, el atajo ⌘K (macOS) o Ctrl+K escuchado en toda la página, la paleta en español con grupos, «Sin resultados» fuera de la lista (una lista vacía falla axe) y una fila de «Buscando…» con spinner, anunciada como estado, mientras los resultados cargan. En el teléfono la paleta queda arriba, para que el teclado no tape los resultados, y el botón no muestra el atajo.

<ComponentPreview name="search-command/demo" />

Este sitio ya usa ⌘K para su propia búsqueda, así que el ejemplo escucha ⌘J (`hotkey="j"`). En tu app deja el valor por omisión, `k`.

## Uso

```tsx
import { SearchCommand, shortcutLabel, type SearchCommandGroup } from '@/components/ui/search-command';

const groups: SearchCommandGroup[] = [
  {
    heading: 'Informes',
    items: [{ id: 'ventas-por-region', label: 'Ventas por región', onSelect: () => router.push('/informes/ventas') }],
  },
  {
    heading: 'Acciones',
    items: [{ id: 'nuevo-informe', label: 'Crear informe', shortcut: shortcutLabel('n') }],
  },
];

<SearchCommand groups={groups} />;
```

Al elegir un ítem corre su `onSelect` y la paleta se cierra. `keywords` encuentra el ítem por otras palabras, como su espacio o su dueño. `shortcutLabel('n')` escribe «⌘N» en Apple y «Ctrl N» en lo demás.

## Cuándo usarlo

- **Una sola búsqueda por app**, en la barra superior: informes, datasets y acciones en un solo lugar.
- **Grupos con nombre** («Informes», «Datasets», «Acciones») y los atajos de las acciones en sus ítems.
- **Resultados del servidor**: `loading` mientras llegan, para no decir «Sin resultados» antes de tiempo.

## Cuándo no

- **Una lista filtrable dentro de una página o un popover**: `Command`.
- **Elegir un valor de un formulario**: `Combobox`.
- **Filtrar una tabla**: la búsqueda de `DataTable`.
