AuraData añade variantes sólidas de estado. Una etiqueta larga se trunca y, si la etiqueta es interactiva, el foco muestra el anillo de marca sin cambiar el borde.

## Uso

```tsx
import { Badge } from '@/components/ui/badge';

<Badge variant="success">Publicado</Badge>;
```

## Cuándo usarlo

- Ponlo junto al nombre de un informe o dataset para que su estado se pueda leer de un vistazo.

## Cuándo no

- Si hay que explicar qué pasó y qué hacer, usa `Alert`; si hay que iniciar una acción, usa `Button`.
