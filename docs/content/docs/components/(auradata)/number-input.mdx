Un campo numérico de AuraData sobre `NumberField` de Base UI: es-MX por omisión, nombres en español para los botones («Disminuir», «Aumentar») y el borde y los estados de los campos de texto. Las flechas suben y bajan `step`, Shift con `largeStep`, y también Re Pág y Av Pág. El valor es un número.

## Uso

```tsx

<NumberInput id="port" defaultValue={5432} min={1} max={65535} format={{ useGrouping: false }} />;
```

## Cuándo usarlo

- **Un número con pasos**: un puerto, filas por página, una cantidad.
- **En formularios**, con `react-hook-form`: no es un input nativo, así que va con `Controller` (`value` y `onValueChange`) y el `ref` en `inputRef`, para que el foco llegue al primer error.

## Cuándo no

- **Dinero**: [Input Group](/docs/components/input-group/) para mostrar la moneda junto al campo.
- **Un valor aproximado en una escala**: `Slider`.
- **Un código o un número que no se suma** (un folio, un código postal): `Input`.
