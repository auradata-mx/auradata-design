Una tabla sobre TanStack Table, en español: orden por columna, búsqueda, columnas visibles y paginación de serie; y, cuando hacen falta, selección con acciones en bloque, filtros por columna, filas compactas, columnas fijas, exportar a CSV o Excel, vistas guardadas y miles de filas virtualizadas. En pantallas angostas se desplaza de lado dentro de su borde.

## Uso

```tsx
import { DataTable, type DataTableColumn } from '@/components/ui/data-table';

type Informe = { nombre: string; espacio: string };

const columns: DataTableColumn<Informe, string>[] = [
  { accessorKey: 'nombre', header: 'Nombre' },
  { accessorKey: 'espacio', header: 'Espacio' },
];

<DataTable columns={columns} data={informes} filterPlaceholder="Buscar informes…" />;
```

## Ejemplos

### Selección y acciones en bloque

Con `selectable`, cada fila lleva una casilla; `rowLabel` le da nombre a cada una. Con `bulkActions`, mientras hay filas seleccionadas flota abajo una barra con el conteo, anunciado con una región viva, y tus acciones. `bulkActions` recibe las filas elegidas y `clear`, que vacía la selección; «Quitar selección» y Escape dentro de la barra también la vacían. Este ejemplo confirma qué informes se marcaron o eliminaron.

<ComponentPreview name="data-table/selection" align="start" />

Las acciones que afectan a una sola fila van en esa fila, no en la barra.

### Vistas guardadas

Con `savedViews`, la barra de herramientas suma un menú «Vistas»: guarda bajo un nombre cómo se ve la tabla (orden, búsqueda, filtros, columnas, tamaño de página y densidad) y vuelve a aplicarla después. Guardar con un nombre que ya existe reemplaza esa vista; el menú dice cuál está aplicada y la deja eliminar. Ordena o filtra, guarda la vista y vuelve a ella desde «Vistas».

<ComponentPreview name="data-table/saved-views" align="start" />

`savedViews="informes"` guarda en `localStorage` bajo esa clave; `savedViews={{ key, storage }}` usa otro almacén con `getItem` y `setItem` (una caché respaldada por el servidor). Este ejemplo guarda en memoria: al recargar se restablece.

### Cargando

Filas esqueleto para una página completa, la región con `aria-busy` y el paginador deshabilitado.

## Cuándo usarlo

- **El detalle que explica los números**: en un tablero va al final, debajo de los KPI y las gráficas.
- **Cuando la pregunta es «¿cuál es el detalle?»**: a veces la respuesta no es una gráfica, es una tabla.
- **Cifras con `tabular-nums`**, para que las columnas se alineen.

## Cuándo no

- **Una lista de cosas para abrir** (informes, conexiones) sin columnas que comparar: una lista de enlaces o tarjetas con acceso a la vista de detalle.
- **Una tendencia o una comparación**: una gráfica (`Chart`).
