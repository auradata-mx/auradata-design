title: Filter builder

`FilterBuilder` ofrece los operadores según el tipo de campo. El usuario arma un árbol de condiciones; el componente edita ese árbol, pero no ejecuta la consulta ni filtra las filas por su cuenta.

<ComponentInstall item="filter-builder" />

## Uso

```tsx
import { FilterBuilder } from '@/components/ui/filter-builder';

<FilterBuilder
  fields={[{ id: 'ventas', label: 'Ventas', type: 'number' }]}
  value={filtro}
  onValueChange={setFiltro}
/>;
```

## Cuándo usarlo

- Cuando necesitas reglas sobre campos distintos o un criterio alternativo dentro de otro. Define el tipo de cada campo para mostrar los operadores correctos.

## Cuándo no

- Para elegir regiones dentro de un solo campo basta `Filter` con `type="select"`. Para mostrar los filtros que ya están activos, usa `FilterChips`.
