El slider de shadcn sobre Base UI con un riel vacío que se ve, en claro y oscuro, y un pulgar con el borde del color del relleno. Con dos valores, dibuja un rango.

<ComponentInstall item="slider" />

## Uso

```tsx
import { Label } from '@/components/ui/label';
import { Slider } from '@/components/ui/slider';

<Label id="ventas-minimas">Ventas mínimas por sucursal</Label>
<Slider aria-labelledby="ventas-minimas" defaultValue={250000} min={0} max={1000000} step={50000} />;
```

## Cuándo usarlo

- **Un filtro numérico aproximado**, donde importa más la posición que la cifra exacta.
- **Con su etiqueta y el valor a la vista**: `aria-labelledby` apunta al `Label`, y el valor actual va a la derecha en cifras tabulares (`tabular-nums`), con su formato (`formatCurrency`, «%»).

## Cuándo no

- **Una cifra exacta**: `NumberInput`.
- **Un rango de montos en una barra de filtros**: `RangeFilter`, que muestra el rango elegido en el botón.
