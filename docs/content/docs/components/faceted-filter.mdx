`FacetedFilter` abre un panel con búsqueda, una casilla por valor y el conteo cuando lo pasas. El botón resume la selección: hasta dos nombres, o un total a partir de tres.

## Instalación

<ComponentInstall item="faceted-filter" />

## Uso

```tsx
import { FacetedFilter } from '@/components/ui/faceted-filter';

<FacetedFilter
  title="Región"
  options={[{ value: 'norte', label: 'Norte', count: 128 }]}
  value={regiones}
  onValueChange={setRegiones}
/>;
```

## Ejemplos

### Selección inicial

Con `defaultValue` eliges cómo empieza el filtro. Para sincronizarlo con la tabla o con los chips de la página, controla `value`.

## Cuándo usarlo

- Para filtrar por varios valores discretos de un mismo campo, como regiones o estados. Pon el nombre del campo en el botón.

## Cuándo no

- Para un intervalo de fechas o números, usa `DateRangeFilter` o `RangeFilter`. Para combinar campos con Y/O, usa `FilterBuilder`.
