## Cuándo usarlo

- Identifica a la persona que publicó un informe o a los miembros de un espacio. Si no hay nombre visible, asegúrate de que la foto o el avatar tenga un nombre accesible.

## Cuándo no

- Para comunicar el estado de un informe, usa `Badge` con texto; un avatar no sustituye una etiqueta de estado.
