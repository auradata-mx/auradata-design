Una tabla sobre TanStack Table, en español: orden por columna, búsqueda, columnas visibles y paginación de serie; y, cuando hacen falta, selección con acciones en bloque, filtros por columna, filas compactas, columnas fijas, exportar a CSV o Excel, vistas guardadas y miles de filas virtualizadas. En pantallas angostas se desplaza de lado dentro de su borde.

## Uso

```tsx
import { DataTable, type DataTableColumn } from '@/components/ui/data-table';

type Informe = { nombre: string; espacio: string };

const columns: DataTableColumn<Informe, string>[] = [
  { accessorKey: 'nombre', header: 'Nombre' },
  { accessorKey: 'espacio', header: 'Espacio' },
];

<DataTable columns={columns} data={informes} filterPlaceholder="Buscar informes…" />;
```

## Cuándo usarlo

- **El detalle que explica los números**: en un tablero va al final, debajo de los KPI y las gráficas.
- **Cuando la pregunta es «¿cuál es el detalle?»**: a veces la respuesta no es una gráfica, es una tabla.
- **Cifras con `tabular-nums`**, para que las columnas se alineen.

## Cuándo no

- **Una lista de cosas para abrir** (informes, conexiones) sin columnas que comparar: `MasterDetail`, una lista y su detalle.
- **Una tendencia o una comparación**: una gráfica (`Chart`).
