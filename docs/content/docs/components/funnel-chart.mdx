title: Funnel chart
description: "Muestra en qué paso se pierde gente y cuántas personas llegan al final."
---

El embudo de AuraData usa barras centradas respecto al primer paso. Cada renglón da el conteo y, desde el segundo, la conversión respecto al paso anterior. Se lee como lista incluso sin ver las barras.

<ComponentInstall item="funnel-chart" />

## Uso

```tsx
import { FunnelChart } from '@/components/ui/funnel-chart';

<FunnelChart data={etapas} index="etapa" value="personas" />;
```

## Ejemplos

### Conversión total con nombre propio

Con `totalLabel`, nombra el resultado del último paso respecto al primero, no el promedio de las conversiones.

## Cuándo usarlo

- **¿Dónde se pierde la gente?** Pasa las etapas en el orden del recorrido. Mantén la misma unidad en todos los pasos.

## Cuándo no

- Para comparar categorías independientes que no son pasos de un recorrido, usa barras horizontales.
