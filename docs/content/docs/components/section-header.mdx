Un componente de AuraData que junta `Eyebrow` y `GradientHeading`: la etiqueta pequeña arriba, el título con sus últimas palabras (`highlight`) en el degradado de la marca, en la misma línea, y un párrafo de entrada. Va alineado a la izquierda o centrado.

<ComponentInstall item="section-header" />

## Uso

```tsx
import { SectionHeader } from '@/components/ui/section-header';

<section aria-labelledby="beneficios">
  <SectionHeader
    titleId="beneficios"
    eyebrow="Por qué AuraData"
    title="Lo que ganas al"
    highlight="trabajar con nosotros"
    description="Software con claridad, propósito y precisión para impulsar tu negocio."
  />
</section>;
```

`titleId` le da un `id` al título, para nombrar la sección con `aria-labelledby`. El título es un `h2`; cámbialo con `as`.

## Cuándo usarlo

- **Al abrir cada sección** de una página de marketing (auradata.mx): qué es, el título y una frase.
- **El degradado en pocas palabras**, el remate del título; el resto, en el color del texto.

## Cuándo no

- **Una página de la app**: `PageHeader`, sin degradado.
- **Solo el título con degradado**: `GradientHeading`.
