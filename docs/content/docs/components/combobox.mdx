El combobox de shadcn sobre Base UI. El botón de la lista tiene nombre y sale del orden de tabulación, como pide axe; el borde del popup va dentro de su caja, como el del select. Con `multiple`, el campo de chips contrasta 3:1, conserva su borde con el foco (solo el contorno de la marca), se vuelve rojo nítido al ser inválido, y el botón de cada chip dice «Quitar» más el nombre del chip.

## Uso

```tsx
import {
  Combobox,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxItem,
  ComboboxList,
} from '@/components/ui/combobox';

<Combobox items={DATASETS}>
  <ComboboxInput id="dataset" placeholder="Busca un dataset" />
  <ComboboxContent>
    <ComboboxEmpty>Sin resultados</ComboboxEmpty>
    <ComboboxList>
      {(dataset: string) => (
        <ComboboxItem key={dataset} value={dataset}>
          {dataset}
        </ComboboxItem>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>;
```

## Ejemplos

### Varios valores

Con `multiple`, la lista sigue abierta después de elegir y cada valor es un chip con su botón «Quitar». Mientras la lista está abierta, Base UI oculta de la tecnología de asistencia todo lo que está fuera del campo (la etiqueta también), así que el input y la lista se nombran con `aria-labelledby`. Backspace en la búsqueda vacía quita el último chip.

## Cuándo usarlo

- **Una lista larga que hay que buscar**: datasets, clientes, sucursales.
- **Varios valores de una lista**: `multiple`; busca, y cada valor es un chip que se quita.
- **Etiquetas libres**: `multiple` con una opción «Crear «…»».

## Cuándo no

- **Una lista corta que se ve de un vistazo**: `Select`.
- **Pocas opciones que conviene ver todas**: `RadioGroup` o `Checkbox`.
- **Buscar en toda la app** (informes, acciones): `CommandSearch`.
