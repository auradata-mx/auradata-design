`ChartCard` envuelve la gráfica con un título, una descripción y, si hace falta, un filtro propio. En su menú puedes exportar la gráfica a PNG o abrir la tabla de «Ver datos» cuando se pasan las filas. La tarjeta conserva su altura al cargar o fallar.

## Uso

```tsx
import { ChartCard } from '@/components/ui/chart-card';

<ChartCard title="Consultas por mes" description="Consultas, agosto a octubre" data={datos}>
  {grafica}
</ChartCard>;
```

## Ejemplos

### Primera carga

Muestra el esqueleto con `loading`. Usa `refreshing` si ya hay una gráfica y solo estás actualizando sus datos.

## Cuándo usarlo

- Cada gráfica de un tablero necesita un **título que diga qué se ve** y una descripción con la unidad y el periodo.
- Pasa los datos de la gráfica para que la tabla del menú sea otra forma de leer los valores.

## Cuándo no

- Si un filtro afecta a todo el tablero, ponlo arriba del grid con el rango de fechas primero, no dentro de una tarjeta.
- Para una sola cifra con su cambio, usa `KpiCard`.
