Un filtro de AuraData por un rango de números: un botón que abre un slider de dos pulgares sobre todo el campo y los dos extremos como números. El slider da la idea del rango; los inputs, la cifra exacta. Un input se aplica con Enter o al salir del campo, nunca mientras se escribe; «Limpiar» quita el rango.

## Uso

```tsx
import { RangeFilter } from '@/components/ui/range-filter';
import { formatCurrency } from '@/lib/format';

<RangeFilter title="Ventas" min={0} max={500000} step={1000} format={formatCurrency} onValueChange={setRange} />;
```

No sabe nada de tablas: `DataTable` crea uno por columna con `meta.filter.type: "range"`.

## Cuándo usarlo

- **Un rango de montos o cantidades** en la barra de filtros de un informe o de una tabla.
- **Con el formato del campo**: `formatCurrency` para dinero; `formatNumber` por omisión.

## Cuándo no

- **Un número en un formulario**: `NumberInput` o `CurrencyInput`.
- **Segmentos** (región, producto): `FacetedFilter`.
- **El periodo**: `DateRangeFilter`.
