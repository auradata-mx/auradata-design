## Cuándo usarlo

- **Texto corto**: el campo de siempre para un nombre, un correo o una búsqueda.
- **Siempre con nombre**: un `FieldLabel` visible o, si no hay espacio (una búsqueda en una barra), un `aria-label`. El placeholder no reemplaza a la etiqueta.
- **Valida al salir del campo o al enviar**, no mientras se escribe.

## Cuándo no

Hay un control para cada dato:

| Dato | Control |
| --- | --- |
| Un número con pasos | `NumberInput` |
| Dinero | [Input Group](/docs/components/input-group/) con la moneda como texto adjunto |
| Teléfono | [Input Group](/docs/components/input-group/#teléfono) con `type="tel"` y un prefijo |
| Contraseña nueva | `PasswordInput` |
| Código de verificación | `InputOTP` |
| Un día o una hora | `DatePicker`, `TimePicker` |
| Texto largo | `Textarea` |
