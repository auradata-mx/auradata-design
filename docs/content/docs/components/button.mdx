El botón de shadcn con lo que AuraData le suma: un destructivo sólido que cumple el contraste AA, un estado `loading` con spinner y `aria-busy`, y profundidad: sube 1 px al pasar el mouse y se hunde al presionarlo.

## Uso

```tsx
import { Button } from '@/components/ui/button';

<Button>Guardar informe</Button>;
```

## Ejemplos

### Variantes

`default` para la acción principal, `outline` y `secondary` para las demás, `ghost` en barras y tablas, `destructive` para borrar y `link` dentro de un texto.

### Con ícono

Dentro de un `Button` el ícono no lleva tamaño: el botón le da 16 px. Junto a un texto es decorativo (`aria-hidden`); un botón solo con ícono necesita `aria-label`.

<ComponentPreview name="button/with-icon" />

### Cargando y deshabilitado

Mientras la acción corre, `loading` pone un spinner, `aria-busy` y lo deshabilita, para que no se envíe dos veces. Cambia también el texto: «Guardando…».

## Cuándo usarlo

- **Una acción**, no una navegación: para ir a otra página usa un enlace. Si debe verse como botón, `buttonVariants` sobre el `Link`.
- **Un solo botón principal por vista.** Las demás acciones van en `outline`, `secondary` o `ghost`.
- **Verbos en la etiqueta:** «Guardar cambios», «Eliminar»; nunca «Aceptar» ni «OK».
- **Un botón solo con ícono** lleva `aria-label` y un `Tooltip` con el mismo texto.

## Cuándo no

- Para elegir una opción entre varias usa `Tabs` o `ToggleGroup`, no un grupo de botones.
- Para borrar algo que no se puede deshacer, el botón `destructive` abre un `AlertDialog` que nombra el objeto y la consecuencia; no borra directo.
