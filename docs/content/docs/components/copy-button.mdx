---

Un botón compacto que copia `value` al portapapeles, transforma el ícono de portapapeles en una palomita verde (`text-success-700`) durante un momento y anuncia «Copiado» mediante una región `aria-live`. `CodeBlockCopyButton` lo usa internamente.

## Instalación

<ComponentInstall item="copy-button" />

## Uso

```tsx
import { CopyButton } from '@/components/ui/copy-button';

<CopyButton value="https://bi.auradata.mx/informes/ventas-2026" />;
```

## Ejemplos

### Con etiqueta visible

Pasa texto como `children` cuando el botón no va pegado a un campo o bloque de código.

## Cuándo usarlo

- Junto a enlaces compartibles, identificadores, claves de API o bloques de código donde la persona necesita copiar sin seleccionar manualmente.

## Cuándo no

- Para duplicar un registro o informe dentro de la app (por ejemplo «Duplicar informe»): usa un `Button` o ítem de menú normal, ya que no copia al portapapeles.
