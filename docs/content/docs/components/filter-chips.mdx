---
title: Filter chips
description: "Muestra qué filtros están activos y deja quitarlos desde un mismo lugar."
---

Cada chip muestra el campo y su valor ya formateado. Su botón quita solo ese filtro; si pasas `onClearAll` aparece «Limpiar todo». Cuando no hay filtros, la tira no se dibuja.

<ComponentPreview name="filter-chips/demo" />

## Instalación

<ComponentInstall item="filter-chips" />

## Uso

```tsx
import { FilterChips } from '@/components/ui/filter-chips';

<FilterChips chips={filtrosActivos} onRemove={quitarFiltro} onClearAll={limpiarFiltros} />;
```

## Ejemplos

### Limpiar todos los filtros

Deja que la vista actualice su estado en `onRemove` y `onClearAll`; los chips reflejan lo que queda.

## Cuándo usarlo

- Cuando los filtros de una página merecen un resumen visible y una forma directa de revertirlos. Usa `lib/format` al escribir fechas, cifras y rangos.

## Cuándo no

- Para agregar opciones a un filtro usa `Filter` u otro control apropiado; los chips no editan el valor.
