`Kbd` dibuja una tecla con un borde visible también sobre superficies claras. Sirve para enseñar el atajo; no registra teclas ni dispara acciones por sí mismo.

## Uso

```tsx
import { Kbd } from '@/components/ui/kbd';

<Kbd>Esc</Kbd>;
```

## Cuándo usarlo

- Junto a una instrucción o en la ayuda de atajos. Muestra la combinación que corresponde a la plataforma.

## Cuándo no

- Si la persona tiene que hacer clic para disparar una acción, usa `Button`. `Kbd` solo muestra una tecla.
