Todos los componentes del registro se instalan directamente en tu código con el CLI de shadcn (`npx shadcn add https://design.auradata.mx/r/<componente>.json`), sobre Base UI y Tailwind 4 con los tokens de AuraData aplicados.

Están ordenados por capa: qué tan lejos están de shadcn. Las combinaciones de componentes no viven aquí: son piezas de los [bloques](/docs/blocks/). Para ver todos los estados visuales y las pruebas de accesibilidad de un componente, abre el enlace a Storybook al final de su página.

## Base

Los componentes de shadcn sobre Base UI con los cambios de AuraData: estados, contraste, textos en español y diseño en el teléfono. Los que shadcn ya resuelve tal cual (`card`, `popover`, `separator`, `skeleton`, `table`…) se instalan directo de shadcn y el tema les da la marca.
