Todos los componentes del registro se instalan directamente en tu código con el CLI de shadcn (`npx shadcn add https://design.auradata.mx/r/<componente>.json`), sobre Base UI y Tailwind 4 con los tokens de AuraData aplicados.

Si buscas pantallas completas listas para ensamblar, revisa la [galería de bloques](/docs/blocks/). Si quieres inspeccionar todos los estados visuales y pruebas de accesibilidad de un componente, abre el enlace a Storybook al final de cada página.
