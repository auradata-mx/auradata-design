En AuraData, el grupo se desvanece en el borde donde hay más archivos. El botón de quitar se alinea en la tarjeta y, si falla la carga, la descripción usa el color de error con contraste AA.

## Uso

```tsx
import { Attachment, AttachmentContent, AttachmentTitle } from '@/components/ui/attachment';

<Attachment>
  <AttachmentContent><AttachmentTitle>ventas.xlsx</AttachmentTitle></AttachmentContent>
</Attachment>;
```

## Cuándo usarlo

- Muestra el nombre, el estado y las acciones de cada archivo ya seleccionado. Incluye el nombre del archivo en la etiqueta de «Quitar».

## Cuándo no

- Para seleccionar o arrastrar archivos, usa `FileDropzone`; `Attachment` no sube los archivos por su cuenta.
