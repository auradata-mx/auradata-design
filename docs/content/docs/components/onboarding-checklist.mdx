La tarjeta de AuraData muestra el avance, destaca la primera acción pendiente y cambia a una confirmación cuando se completan todos los pasos.

<ComponentPreview name="onboarding-checklist/demo" />

## Instalación

<ComponentInstall item="onboarding-checklist" />

## Uso

```tsx
import { OnboardingChecklist } from '@/components/ui/onboarding-checklist';

<OnboardingChecklist
  steps={[
    { id: 'connect', title: 'Conecta tu primera base de datos', action: { label: 'Conectar', href: '/conexiones' } },
  ]}
/>;
```

## Ejemplos

### Guía completada

Al completar los pasos, la confirmación reemplaza la lista. Con `onDismiss`, la tarjeta ofrece «Listo» para ocultarla.

## Cuándo usarlo

- Para los primeros pasos del producto que pueden completarse en momentos distintos. Guarda el progreso y la preferencia de ocultar en la app.

## Cuándo no

- Para un formulario con pasos que se completan en orden, usa `Stepper`, no una lista de tareas independientes.
