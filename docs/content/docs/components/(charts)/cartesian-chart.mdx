---
title: Cartesian chart
description: "Compara categorías y periodos con líneas, áreas, barras o una combinación."
---

`LineChart`, `AreaChart`, `BarChart` y `ComboChart` aplican la paleta Aura en orden, escriben ejes y tooltips en es-MX y dejan ocultar series desde la leyenda. Elige la forma según la pregunta; los datos conservan la misma estructura.

## Instalación

<ComponentInstall item="cartesian-chart" />

## Uso

```tsx
import { LineChart } from '@/components/ui/cartesian-chart';

<LineChart data={ventas} index="mes" series={{ norte: 'Norte', sur: 'Sur' }} />;
```

## Cuándo usarlo

- **¿Cómo cambia?** Usa líneas. Para acumulación elige área; para comparar categorías, barras. Barras y áreas siempre parten de cero.
- **¿Vamos contra la meta?** Usa `ComboChart` con una sola unidad. Con dos o más series conserva la leyenda.

## Cuándo no

- Para dos unidades distintas usa dos gráficas, no dos ejes.
- Para el detalle detrás de los puntos, ofrece «Ver datos» en `ChartCard` o una `DataTable`.
