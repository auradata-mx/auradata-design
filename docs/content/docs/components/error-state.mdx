## Uso

```tsx

<ErrorState
  title="No se pudo cargar el informe"
  description="Revisa la conexión en Ajustes e inténtalo de nuevo."
/>;
```

## Cuándo usarlo

- Úsalo donde debía aparecer el contenido si un error lo bloqueó. Explica qué pasó sin culpar a la persona y da un siguiente paso.

## Cuándo no

- Si no hubo error y simplemente no hay datos, usa `Empty`. Para un aviso al lado de contenido que sigue disponible, usa `Alert`.
