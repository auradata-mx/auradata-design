title: Field
description: "Junta la etiqueta, el control, la ayuda y el error de cada dato de un formulario."
---

El field de shadcn con el ritmo de AuraData: la leyenda de un `FieldSet` guarda el mismo espacio que los campos debajo, las descripciones no dejan una palabra sola en la última línea, una tarjeta de opción enfocada no cambia de borde y la leyenda de un grupo inválido se vuelve destructiva como la etiqueta de un campo.

## Uso

```tsx
import { Field, FieldDescription, FieldError, FieldLabel } from '@/components/ui/field';
import { Input } from '@/components/ui/input';

<Field>
  <FieldLabel htmlFor="name">Nombre</FieldLabel>
  <Input id="name" />
  <FieldDescription>Así lo verá tu equipo.</FieldDescription>
</Field>;
```

| Parte | Para qué |
| --- | --- |
| `Field` | Un dato: etiqueta, control, ayuda y error |
| `FieldLabel` | El nombre del control (`htmlFor`) |
| `FieldDescription` | La ayuda, en una línea, debajo del control |
| `FieldError` | Qué está mal y cómo corregirlo |
| `FieldSet` y `FieldLegend` | Un grupo de campos o de opciones con su título |
| `FieldGroup` | Apila los campos con el espacio de la marca |
| `FieldContent` | La etiqueta y la ayuda juntas, al lado del control |

## Ejemplos

### Horizontal

Etiqueta y control en una fila (`orientation="horizontal"`), como un switch con su descripción.

### Inválido

`data-invalid` en el `Field` pone la etiqueta en destructivo; `aria-invalid` en el control pinta su borde; `FieldError` dice cómo corregirlo, en la voz de la marca.

## Cuándo usarlo

- **Cada control de un formulario** va en un `Field`, con su `FieldLabel`. El placeholder no reemplaza a la etiqueta.
- **Valida al salir del campo y al enviar** (`mode: "onTouched"` en react-hook-form), no mientras se escribe.
- **El error dice qué hacer**: «Escribe un correo completo, como ana@empresa.mx», no «Correo inválido».
- **Los errores del servidor que no son de un campo** van en un `Alert` arriba del formulario, no en un `FieldError`.

## Cuándo no

- **Un control suelto fuera de un formulario** (un checkbox en una barra): `Label`.
- **Un control con texto o botones dentro** (un «$», un botón de copiar): `InputGroup`, dentro del `Field`.
