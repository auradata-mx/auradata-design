# Banco de pruebas de AuraData

Este Storybook es el banco de pruebas del sistema de diseño: cada estado de cada componente y bloque, con sus pruebas visuales y de accesibilidad en claro y oscuro.

La guía de marca, los tokens y la documentación de uso viven en el sitio de docs, que es la única fuente de verdad:

- <a href="https://design.auradata.mx/docs/brand/" target="_top">Guía de marca</a>: identidad, logotipo, tipografía, color, voz y patrones.
- <a href="https://design.auradata.mx/docs/components/" target="_top">Componentes</a>: cuándo usar cada uno, sus props y el comando para instalarlo.
- <a href="https://design.auradata.mx/docs/installation/" target="_top">Instalación</a>: cómo agregar el registro a un proyecto con `npx shadcn add`.

Cada historia tiene un botón **Docs** en la barra superior que abre la página de su componente.
